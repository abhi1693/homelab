# Student 4 NetBox

This lab is paused. Web and worker replicas are zero and public ingress is disabled. The web and worker use PostgreSQL database `netbox_student4` and Valkey indexes 20/21. Authorized operators can retrieve the bootstrap password from `student4-netbox-admin` in namespace `student4`.

The web and worker load NetBox DNS and NetBox Branching from the pinned student image.
