# Student 2 NetBox

This lab is paused. Web and worker replicas are zero and public ingress is disabled. The web and worker use PostgreSQL database `netbox_student2` and Valkey indexes 16/17. Authorized operators can retrieve the bootstrap password from `student2-netbox-admin` in namespace `student2`.

The web and worker load NetBox DNS and NetBox Branching from the pinned student image.
