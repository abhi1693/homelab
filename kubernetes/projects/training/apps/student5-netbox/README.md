# Student 5 NetBox

This lab is paused. Web and worker replicas are zero and public ingress is disabled. The web and worker use PostgreSQL database `netbox_student5` and Valkey indexes 22/23. Authorized operators can retrieve the bootstrap password from `student5-netbox-admin` in namespace `student5`.

The web and worker load NetBox DNS and NetBox Branching from the pinned student image.
