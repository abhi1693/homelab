# Student 3 NetBox

This lab is paused. Web and worker replicas are zero and public ingress is disabled. The web and worker use PostgreSQL database `netbox_student3` and Valkey indexes 18/19. Authorized operators can retrieve the bootstrap password from `student3-netbox-admin` in namespace `student3`.

The web and worker load NetBox DNS and NetBox Branching from the pinned student image.
